# FitTime — сервис онлайн-записи на занятия в фитнес-центре

**Авторы** Ботвиньев Максим, Песчасов Кирилл
**Группа:** ИСиП-31,32

## О проекте

FitTime — учебный проект информационной системы, которая помогает клиентам фитнес-центра просматривать расписание и записываться на занятия. Администратор управляет расписанием и занятиями, а тренер получает информацию о своих занятиях и участниках.

## Цель проекта

Упростить запись на тренировки, уменьшить ручную работу администратора и сделать расписание доступным клиентам.

## Основные роли

- **Клиент** — просматривает расписание, записывается и отменяет запись.
- **Администратор** — управляет занятиями и расписанием.
- **Тренер** — просматривает информацию о своих занятиях и участниках.

## Инструменты разработки

- Visual Studio Code — среда разработки.
- Git — система контроля версий.
- GitHub — хранение репозитория.
